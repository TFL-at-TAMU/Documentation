  1. **The Cut**



Next it is time to cut the shape out. 

  * These example photos use copy paper, however this project is meant to be done with cardstock and scaled up. 



Press the make button that is on the top right hand side of the screen 

![](../../assets/images/cricut_explore_4_ass_130e3c6bf4.png)

Select the on mat button and ensure that the mat is the same dimensions as the one you are using which in this case is 12 x 12. 

Wait for your machine to pair with the Cricut 

![](../../assets/images/cricut_explore_4_ass_8d5e2eec5d.png)

Then you will go to this screen

![](../../assets/images/cricut_explore_4_ass_f9d45b53e5.png)

Press on the appropriate card stock button. 

Then the next step will prompt ![](../../assets/images/cricut_explore_4_ass_ef51f9d456.png)

Follow the prompts, the final step after loading will be to press the go button and do the cut. 

To the materials before the load 

![](../../assets/images/cricut_explore_4_ass_db4fdaff84.jpeg)

Attach your cardstock to the mat 

Place the mat within the guardrails of the cricut, and press the load button. 

Then press the go button 

![](../../assets/images/cricut_explore_4_ass_1373099167.jpeg)

This is how the cut should look. 

Cut this out twice, repeat the process to cut this shape again.
